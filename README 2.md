# Mi pizarra de estudio

Repositorio para estudiar: apuntes por asignaturas y una web con tarjetas de repaso y tests.

## Qué hay aquí

- `index.html`: la web de estudio (no hace falta tocarla).
- `temas.js`: aquí están todos los temas, tarjetas y preguntas. Es el único archivo que se edita para añadir temas.
- `apuntes/`: apuntes en texto, una carpeta por asignatura.

## Temas

| Asignatura | Tema |
|---|---|
| Inglés | Verbos modales |
| Inglés | Logros (Achievements) |
| Inglés | Acontecimientos de la vida (Life events) |

## Cómo añadir un tema nuevo

1. Abre `temas.js` y pulsa el lápiz para editar.
2. Pega el bloque del tema nuevo al final de la lista, separado por una coma.
3. Guarda con **Commit changes**. En un minuto aparece en la web.
