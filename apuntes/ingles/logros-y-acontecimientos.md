# Logros y acontecimientos de la vida

## Logros (Achievements)

| Inglés | Español |
|---|---|
| publish a book | publicar un libro |
| win a prize | ganar un premio |
| create a website | crear una página web |
| paint a picture | pintar un cuadro |
| write music | componer música |
| make a film | hacer una película |
| invent things | inventar cosas |
| become rich | hacerse rico |
| play in a band | tocar en un grupo musical |
| start a business | empezar / abrir un negocio |
| become famous | hacerse famoso |
| release an album | lanzar un álbum |
| participate in a competition | participar en una competición |
| earn money | ganar dinero (trabajando) |

**Ojo:** *win* es ganar un premio o una competición; *earn* es ganar dinero trabajando.

## Acontecimientos de la vida (Life events)

| Inglés | Español |
|---|---|
| be born | nacer |
| have a baby | tener un bebé |
| grow up | crecer |
| go to university | ir a la universidad |
| get a job | conseguir un trabajo |
| work for | trabajar para |
| get engaged | comprometerse (matrimonio) |
| get married | casarse |
| get divorced | divorciarse |
| move (to) | mudarse (a) |
| retire | jubilarse |
| die | morir |

**Truco:** muchas van con *get*: get engaged, get married, get divorced, get a job.

**Ojo:** nacer en pasado es *I was born*, no "I borned".
