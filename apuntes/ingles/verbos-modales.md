# Verbos modales (Modal verbs)

Son verbos que acompañan a otro verbo para expresar capacidad, permiso, obligación, consejo o posibilidad.

## Regla de oro

Después de un modal, el verbo va **sin "to"** y **sin "-s"**.

- ✅ She can drive.
- ❌ She cans drive. / She can to drive.

## Tabla resumen

| Modal | Para qué sirve | Ejemplo |
|---|---|---|
| can | capacidad, permiso informal | I can swim. |
| could | pasado de can, petición educada | Could you help me? |
| may | permiso formal, posibilidad | May I come in? |
| might | posibilidad baja | It might rain. |
| must | obligación fuerte, deducción segura | You must wear a helmet. |
| mustn't | prohibición | You mustn't smoke here. |
| have to | obligación por norma externa | I have to work on Saturday. |
| don't have to | no es necesario | You don't have to come. |
| should | consejo | You should rest more. |
| would | condicional, petición educada | Would you like a coffee? |

## Truco para no confundir

- **mustn't** = no puedes (está prohibido).
- **don't have to** = no hace falta (pero si quieres, puedes).

## De informal a formal

| Informal | Formal |
|---|---|
| Can I go? | May I go? |
| Can you help me? | Could you help me? / Would you mind helping me? |
| You should... | It would be advisable to... |
